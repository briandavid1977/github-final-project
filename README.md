# Simple Interest Calculator

This repository contains a Bash script that calculates simple interest based on user input.

## Description

The Simple Interest Calculator asks the user to enter the principal amount, annual rate of interest, and time period in years. It then calculates and displays the simple interest.

## Formula

Simple Interest = Principal × Rate × Time / 100

Where:

- Principal (p) = initial amount of money
- Rate (r) = annual rate of interest
- Time (t) = time period in years

## How to Use

Run the `simple-interest.sh` script and enter the requested values for principal, rate of interest, and time period.

## Example

Principal: 1000  
Rate of Interest: 5  
Time: 2 years  

Simple Interest = 100
